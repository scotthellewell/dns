Notes

  • BIND 9: The industry standard, extremely feature-rich but complex configuration
  • PowerDNS: Split architecture (Authoritative + Recursor), SQL backend support
  • Knot DNS: High-performance authoritative-only, requires Knot Resolver for recursion
  • CoreDNS: Plugin-based architecture, popular in Kubernetes environments
  • Unbound: Recursive-only resolver focused on security and performance
  • dnsmasq: Lightweight DHCP/DNS forwarder for small networks
  • Pi-hole: Network-wide ad blocker, uses dnsmasq or unbound underneath
  • NSD: Authoritative-only server from NLnet Labs, pairs with Unbound
  • AdGuard Home: Privacy-focused DNS with ad blocking, similar to Pi-hole
  • Technitium: Full-featured DNS server with web UI, similar goals to this project
