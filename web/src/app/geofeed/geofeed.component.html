About Geofeeds

A geofeed (RFC 8805, RFC 9632) is a CSV file that maps IP address prefixes to their geographic locations. This data is consumed by Regional Internet Registries (RIRs), geolocation databases (MaxMind, IPInfo), and CDN providers to improve IP geolocation accuracy.

Usage

  • Add this URL to your RIR's inetnum/inet6num geofeed attribute
  • Reference it in RPSL objects for your IP allocations
  • The CSV is publicly accessible at {{csvUrl}}
